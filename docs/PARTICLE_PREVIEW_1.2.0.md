## 本模组的实现

粒子动作是未保存的实时草稿，目标粒子可能来自当前整合包的任意已注册简单粒子。预览页直接使用当前客户端世界和玩家作为场景，不要求预先制作 Ponder 结构或安装新的依赖。

点击“预览完整动画”后：

1. 校验当前表单中的粒子类型、数值范围和 256 个粒子的总预算。
2. 保留未保存的表单值，打开独立预览页并切换至背后第三人称视角。
3. 与服务端粒子动作一致，在第 0 tick 发射首波，再按 `intervalTicks` 发射，直到 `durationTicks` 结束；散点、向内和向外运动分别模拟对应动作。
4. 结束后等待 20 tick 自动重播。可手动重播、暂停后续发射和切换正面视角。
5. 关闭预览页时恢复进入前的视角并返回粒子编辑表单。

预览只向当前客户端添加粒子，不写入世界、数据包或服务端状态。它展示的是实时世界而非 Ponder 的隔离结构舞台；客户端粒子设置与其他模组的粒子工厂仍会影响实际显示。

## 复合动画与返回路径

获得时、合成时、移除时，以及事件触发器正常动作和失败补救动作列表均提供“预览本组粒子”。预览从当前草稿按列表顺序提取粒子动作，让每项在第 0 tick 同时开始，并分别使用自己的时长、间隔、锚点、运动方式、粒子类型和数量。非粒子动作、触发条件与 `enabledWhen`/`disabledWhen` 不在预览中执行。最多 8 项动画，首波总量不超过 128 个，单项仍保留 256 个总粒子的限制。

从事件编辑器的高级页进入表达式条件或动作列表，返回后会留在事件编辑器的高级页；高级页再次按“返回”则回到此前的事件选项卡。高级子页写入的动作会同步到事件编辑器的工作草稿，避免随后点击“应用”时被旧草稿覆盖。
