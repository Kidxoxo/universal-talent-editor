# 1.3.0 编辑器体验优化

更新日期：2026-10-13。对应 `EDITOR_UX_REVIEW.md` 检查报告。

## 草稿与保存

天赋、稀有度、抽取池、计数器、物品和布局共用保存状态。修改后显示“有未保存的更改”；返回或 Escape 时可继续编辑、放弃改动或保存并返回。局部模块属性、格位绑定和触发器页面提供相应的应用确认。调整窗口尺寸、离开确认后继续编辑会保留文字输入。

“保存更改”按当前启用状态提交，不会强制启用定义。`Ctrl+S` 在定义页保存，在画布应用到上级布局草稿。保存和验证等待期间阻止重复提交；每次提交携带独立请求 ID，结果只交给对应页面。验证不写入世界，也不因序列化过程而修改本地草稿。协议因此升级到 **45**，客户端和服务端都应安装本次 1.3.0 构建。

高级触发条件、成功动作和失败动作编辑独立的触发器草稿。打开高级子页不会提前修改天赋；触发器页应用后才交给天赋草稿。服务器的权限、版本冲突检测、定义校验和事务备份继续保留。

有错误或警告时点击底部状态，可滚动查看完整严重程度、代码、来源、路径和消息，并复制全部详情。复杂嵌套字段目前通过路径定位，没有自动跳转到所有高级表单字段。

## 入口精简

- 定义详情的“更多”统一提供引用、删除和复制为新定义。删除沿用引用检查。副本先输入新 ID，只有保存后才写入；已有 ID 不允许作为副本目标。
- “书页布局”入口改为“界面布局”，同时管理天赋册和抽取页。
- 物品编辑页收拢为外观、常用功能和高级功能；计数器的过滤、增量、重置和元数据归入“计数规则”。演出新增入口分为文字、声音以及高级粒子/变换。
- 图层按钮在宽屏折叠/展开侧栏，窄屏弹出图层列表。属性不足一页时隐藏翻页按钮。
- 单独验证、JSON、表现与行为动作、局部撤销和服务器事务历史继续保留。

## 画布与属性

通过图层属性设置别名和锁定。锁定模块仍参与游戏渲染，可从图层列表选中并解锁，但不会被误拖动或参与多选移动、对齐和样式粘贴。

按住 `Ctrl` 点选多个模块；`Ctrl+A` 选择未锁定模块。拖动或方向键移动整组选区；`Shift+方向键` 移动 10 个单位。“排列”支持六种对齐、水平/垂直等距分布、图层顺序和复制/粘贴样式。分布需要至少三个可编辑模块。单模块对齐以画布为参考，多模块以选区边界为参考。样式粘贴不会覆盖位置、绑定、文字内容、动作入口、别名或锁定状态。

不可复制/删除的候选卡、锁定模块以及书页引用格位会提前禁用相应按钮，附带说明。排列菜单中不适用的操作显示灰色。“预览”统一提供画布交互和全屏两种模式；“更多”收纳恢复选项及应用后编辑书页内容的入口。

属性按几何、外观和内容分组。非交互模块隐藏悬停属性；只有天赋册“进入抽取”按钮显示目标池；图片和文字只提供各自有效的绑定选项。隐藏属性保留原数据。宽度至少 700 个逻辑像素时，属性页右侧显示实时预览；较小窗口使用分页表单。

颜色支持 `#AARRGGBB`、色板和 A/R/G/B 滑块；不透明度支持精确数字及百分比滑块。颜色 Alpha 与模块不透明度相乘。数字输入提示范围，格式错误注明具体字段。各层分别显示“应用到画布 / 应用到书页 / 应用到布局”；最终仍需在布局页保存。

这次没有增加逐页独立 UI 文档，也没有将每一层取消能力合并为一次全局提交。

## 资源、列表和整包管理

定义列表记住搜索、筛选、选中项和滚动位置，并使用新同步的数据。定义列表和资源列表支持上下选择与 Enter。资源选择器增加纹理缩略图、尺寸、命名空间、最近使用及“导入并选用”；批量导入后统一重载仍可使用。资源和效果列表底部不足一行的空白区域不会选择未显示条目。

设置分为“运行设置”和“导入 / 导出”。运行开关立即保存；操作期间显示处理状态并禁用重复提交。导入先展示归档路径、目标世界、各类定义数量、资源数量与替换范围；确认时核对归档 SHA-256，内容变化则要求重新预览。实际导入仍执行原有校验、备份与失败回滚。

导入替换当前世界的编辑器定义，并更新该游戏实例共用的托管资源包。全局模板按钮另有范围确认：影响之后新建的世界，不自动改写已有存档。
