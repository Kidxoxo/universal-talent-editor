# 编辑器统一样式（1.3.0）

本次统一覆盖 65 个编辑页面，包括主页、天赋与物品编辑、稀有度、抽取池、计数器、布局与画布、资源选择、历史与确认页。

## 视觉约定

- 深蓝渐变背景、统一顶部标题栏与底部操作区；表单和分组使用同一组面板颜色及细边框。
- 浅青色用于悬停、焦点和当前选项；保存、应用和新建等入口使用更醒目的主按钮。
- 删除操作使用低饱和红色，禁用按钮降低对比度；焦点轮廓区别于普通悬停。
- 主页和五类定义列表使用双行信息：名称在上，ID、来源与配置摘要在下。连续行底色、细分隔线和选中标记保持一致；天赋编辑分组保留标题与摘要。底部未完整显示下一行的空白不再触发该行的打开操作。
- 输入框统一边框，焦点使用浅青色。保留 Minecraft 的光标、文本选择、滚动、快捷键和朗读行为。
- 弹出选项与放弃草稿确认使用同一套面板、按钮和文字颜色。Escape 仍取消确认。

## 开发入口

`EditorTheme` 集中维护配色、背景、标题、面板、列表行和按钮语义。

编辑页面继承 `EditorScreen`，通过 `renderBackground` 绘制共用背景，通过 `EditorTheme.title` 绘制标题。按钮由 `EditorWidgets.button` 创建；它仍使用原版 Button 的构建、点击、焦点、提示和朗读接口，只替换绘制。

画布内容与正式天赋册、抽取页继续由作者的 UI 文档决定；共用编辑主题不覆盖自定义图片、透明度和按钮样式。粒子/演出预览保留世界画面，仅统一其编辑控件。

## 验证

独立开发客户端使用工作区内的截图入口展示主页、天赋表单、布局、画布、属性、计数器、物品、稀有度、弹出选项和确认页，分别检查两档 GUI 缩放。截图入口不发服务端操作请求、不载入存档，并在正式打包前通过 clean build 排除。

已检查开发客户端的真实截图，并修正物品编辑页首行标签与标题区过近、面板延伸到底部操作区的问题。最终测试数量、截图检查结果和发行文件校验值以发布目录的 `BUILD_VERIFICATION.json` 为准。目标整合包的实机操作仍需在 `test1` 中验证。
