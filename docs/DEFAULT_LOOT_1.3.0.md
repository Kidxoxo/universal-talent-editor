# 天赋点默认战利品（1.3.0）

天赋点默认使用现有物品战利品规则：每次生成宝箱战利品时，以 5% 概率额外生成 1 个天赋点，不受幸运值影响。重新打开已经生成战利品的宝箱不会再次抽取。

规则覆盖原版及模组的 `命名空间:chests/...`、`命名空间:chest/...` 战利品表，包括村庄等子目录。不会匹配普通箱子的方块掉落、怪物掉落或钓鱼表。采用其他路径命名的模组宝箱，可以在编辑器中添加对应规则。

修改入口：**F8 → 物品 → 天赋点 → 战利品**。可调整概率、数量、匹配范围，或删除规则以关闭掉落。规则随物品配置导入和导出，不存在隐藏的额外随机掉落逻辑。

内置定义位于 `data/talent_editor/talent_editor/items/talent_point.json`：

```json
{
  "tableMatch": "regex",
  "table": "[a-z0-9_.-]+:chests?/.*",
  "chance": 0.05,
  "chancePerLuck": 0.0,
  "minCount": 1,
  "maxCount": 1
}
```

如果已有世界或导入包保存了自己的 `talent_editor:talent_point` 物品定义，以该定义为准，不覆盖既有设置。本次涟漪之篇天赋包不重复定义该内置物品，直接使用新版模组的默认规则。
