# 1.3.0 界面可视化编辑

适用于 Minecraft 1.20.1 / Forge 47.3.22–47.x / Java 17。游戏数据仍使用 Schema 2，网络协议升级为 45，客户端与服务端须一起更新。

## 入口和保存

1. 管理员按 **F8 → 天赋册布局 → 新建或编辑布局**。
2. 选择 **天赋册 UI** 或 **抽取 UI**。第一次打开以现有界面为编辑基础，保留原有默认布局、背景、格位和原版按钮风格。
3. 在画布上编辑，点击 **应用草稿** 返回布局页面。
4. 点击 **保存更改**（保存时自动校验）；需要只检查而不写入时使用 **仅验证**。界面将随当前活动布局同步给玩家。

同一份布局可以只编辑天赋册、只编辑抽取页，或同时编辑。多个布局仍按 `enabled` 和 `priority` 选出一个活动布局；本版没有为每个抽取池分别选择界面的规则。

应用草稿只是修改当前编辑页的数据；保存更改才写入世界。保存继续使用服务端 2 级权限检查、完整定义校验、revision 冲突检测、备份和原子文件替换。普通玩家不会因自定义按钮获得管理员权限。

## 布局入口合并

主页面只保留布局 ID、优先级、启用状态、实际加成显示，以及两个 UI 编辑入口和“书页内容”。原来的行列/尺寸表单、自由格位画布、逐页几何画布与独立预览入口已合并，不再同时维护几套位置编辑功能。

- **天赋册 UI / 抽取 UI**：统一编辑背景、透明度、模块位置、文字、按钮样式和功能。
- **书页内容**：新增、排序和删除前置页面，设置页面 ID、背景覆盖与固定天赋绑定。进入“天赋格内容”后可绑定天赋、恢复自动填充、追加格位或缩减末尾空格。
- **画布 → 更多 → 全屏预览**：与画布交互预览使用同一套渲染代码。

默认书页以 480×270 为参考尺寸，沿用左侧 60%、2 列 3 行、48 像素图标、右侧详情和底部原版按钮。已有布局优先从第一张配置书页的几何开始，没有前置页时使用原自由格位或规则网格。所有前置页继续共用这一份 UI；转换不会把每页的不同位置自动合成多份 UI。抽取模板保留标题、摘要、候选卡片和底部操作区。

之前已保存的 1.3.0 自定义 UI 会原样打开。要改用现有默认界面作为基础，选择 **更多 → 从现有默认界面重建**；这会替换当前画布草稿，可撤销，不会改动书页内容绑定。

## 画布操作

| 操作 | 方法 |
|---|---|
| 选择模块 | 左键模块；宽窗口左侧常驻图层列表，窄窗口使用顶部“图层列表” |
| 移动 | 按住左键拖动 |
| 改变尺寸 | 拖动选中模块的右下角方块 |
| 属性 | 右键模块、Enter 或“模块属性”；按“位置尺寸 / 外观样式 / 内容功能”分组 |
| 小幅调整 | 方向键移动 1 单位，Shift + 方向键移动 10 单位 |
| 网格吸附 | “吸附：N”在 1 / 4 / 8 单位间循环；拖动时按 Shift 临时精调 |
| 图层 | “上移图层 / 下移图层”；靠后的模块后绘制、优先接收点击 |
| 复制 / 删除 | 工具栏，或 Ctrl+D / Delete |
| 撤销 / 重做 | 工具栏，或 Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z；最多保留 64 步 |
| 应用草稿 | 工具栏或 Ctrl+S |
| 预览 | “交互预览 / 返回编辑”切换；更多菜单可打开全屏预览；抽取、刷新、合成只模拟 |
| 缩放画布 | Ctrl + 滚轮，范围 50%–400%，围绕鼠标缩放 |
| 平移画布 | 鼠标中键拖动 |
| 恢复视野 | “适应画布”或 Home |

一次完整拖动算一步撤销。撤销后进行新编辑会清除重做分支。取消画布、书页内容或布局主页面时若有未应用/保存的改动，会询问是否放弃；更多菜单中的“还原本次”恢复进入画布时的版本，并可撤销。

画布默认 480×270，可修改宽高。正式界面和全屏预览等比缩放、居中适配窗口；编辑画布额外支持缩放和平移，不拉伸文字或点击区域。九种锚点相对设计画布定位；改变锚点时保留当前可见位置。非常小的窗口仍会让内容缩小，建议在实际 GUI 缩放设置下检查。

## 模块与样式

- **色块面板 / 图片**：背景或装饰，可任意排列与重叠。
- **文字**：自定义文本，或绑定页面标题、状态摘要、页码、幸运与概率、抽取反馈。天赋册摘要仅显示拥有数量；抽取次数和刷新次数在抽取页显示。
- **功能按钮**：可选原版按钮或自定义色块/图片风格，编辑标签、正常/悬停图片和入口功能。原版风格使用 Minecraft 按钮底图，颜色字段用于自定义风格。
- **天赋格**：按索引显示当前页的天赋，点击选择；计数器栏目使用同一组格位。
- **详情区**：显示选中天赋的说明、可见属性和合成需求，正文支持滚动。
- **抽取卡片**：按候选索引显示卡片，支持选择、说明滚动和属性显示切换。

每个模块都有位置、尺寸、不透明度、颜色、纹理；含文字的模块可调整字色、缩放、对齐和偏移。天赋格、详情和卡片还支持图标大小与位置、名称位置、稀有度位置和正文起点。文字受模块边界裁剪；长正文显示滚动条。

颜色表单使用 `#AARRGGBB`，例如 `#80305070`；AA 为该颜色的 alpha。整体不透明度为 0–1，会与颜色 alpha 相乘，0 表示不可见且不接受点击。PNG 的透明通道也会保留。图片目前铺满模块矩形，暂无九宫格切片、视频、GIF 或时间轴动画。

纹理字段旁的“…”可搜索已有客户端 PNG 资源。没有资源时，先从 **F8 → 本地资源** 导入 PNG/JPG/JPEG 并统一重载，再在属性页选择。填写示例：`my_pack:textures/ui/book.png`，不是磁盘路径或网址。找不到纹理时显示紫色占位和属性页提示。

天赋册模板的背景模块绑定当前书页背景，优先显示 `pages[].background`，该页未设置时使用背景模块自身的纹理；希望使用固定图片时，把该模块的动态绑定切到“无绑定 / 自定义内容”（空绑定），然后选择纹理。抽取页的背景独立配置。

## 按钮功能

天赋册支持：关闭、进入抽取、轮换栏目、直接进入已拥有/合成/计数器栏目、合成选中天赋、上一页、下一页。

“进入抽取”按钮可以填写目标抽取池 ID，或点击“…”从已有池中选择，留空使用 `talent_editor:default`。显式目标池必须存在；目标也纳入定义引用检查。其余功能不使用目标 ID。

抽取页支持：关闭、确认当前候选、刷新候选、显示/隐藏属性。按钮仍受服务端抽取会话、代币、条件和冷却规则约束；等待抽取/刷新结果时不能重复提交。启用自动合成时，手动合成与合成栏目入口禁用。

## 与 1.2.0 布局的关系

没有 `bookUi` / `drawUi` 字段时使用原界面，旧配置不需要迁移。“更多 → 使用旧界面”会从草稿中移除对应的新字段，保存后恢复原布局。

自定义天赋册使用一组跨页复用的模块位置；已有 `pages[].slots[].talent` 固定绑定和前置页顺序继续生效。自定义格位数必须不少于任一已有前置页的格位数，额外天赋继续生成后续页。自定义模式下，格位的几何由新模块决定，旧 `slots` 的坐标只在旧界面中使用。前置页缺少的格位与未拥有的固定目标留空。被前置页引用的格位不能直接从画布删除；先在“书页内容”中清除末尾绑定并缩减格位，避免索引移动后绑定错位。新建/追加的内容格位自动分配合法的旧版兼容坐标；已有坐标和绑定保留。预览使用示例或已同步天赋数据，不代表目标玩家实际持有情况。

抽取页保留候选索引 0–4 共五个模块，以覆盖现有抽取池的 1–5 个候选上限。可以移动和改样式，但不能删除或复制候选模块。没有对应候选的模块不显示，其他卡片保持各自设置的位置。

## 分发和边界

布局随世界数据包及现有导入/导出流程保存。客户端图片继续由资源包提供；多人游戏需向每个客户端分发相同资源包。资源诊断目录已包含新 UI 的正常与悬停图片。

本版编辑的是天赋册与抽取界面。没有替换 Minecraft 启动加载页，也没有实现 FancyMenu 布局导入、任意脚本/命令按钮、多选成组编辑或逐页独立 UI 文档。

完整字段说明见 [UI 数据格式](UI_SCHEMA_1.3.0.md)。开发基础和参考项目见 [开发梳理](PROJECT_REVIEW_1.3.0.md)。

本轮草稿、画布排版、资源选择与导入预览的详细说明见 [编辑器体验优化](EDITOR_UX_1.3.0.md)。
