# Universal Talent Editor 1.2.0

适用于 Minecraft 1.20.1 / Forge 47.3.22–47.x 的游戏内天赋编辑器。模组本体无需额外前置；使用其他模组的属性、物品或效果时，仍需安装相应模组。

## 安装与使用

将 `talent_editor-forge-1.20.1-1.2.0.jar` 放入客户端和服务端的 `mods` 目录，使用 Java 17 启动游戏。管理员按 `F8` 打开编辑器，玩家按 `J` 打开天赋册；按键可在控制设置中修改。联机时客户端与服务端应使用相同版本。

编辑器可配置天赋、稀有度、抽取池、计数器、进阶与合成关系、天赋册布局及自定义物品。天赋支持属性、事件动作、条件、生命周期、HUD 与玩家模型表现；“天赋树预览”可查看并编辑天赋之间的关系。配置和资源包可在游戏内导入、导出。

1.2.0 增加获得与合成演出时间轴，可配置文字、音效、粒子和玩家模型演出并进行完整预览。配置物品支持属性列表、多装备槽勾选及 Curios 饰品槽位设置。

存档中的配置位于 `<世界>/datapacks/talent_editor_generated/`。自定义图标、背景和音效需要客户端资源包；多人游戏不会自动向其他玩家分发本地资源文件。

## 构建

使用 Java 17 执行 `./gradlew build`（Windows 为 `gradlew.bat build`）。JAR 与源码 JAR 位于 `build/libs/`，详细配置格式见 [文档](docs/SCHEMA_V2.md)。
