# Universal Talent Editor 1.3.0

适用于 Minecraft 1.20.1 / Forge 47.3.22–47.x 的游戏内天赋编辑器。模组本体无需额外前置；使用其他模组的属性、物品或效果时，需安装相应模组。

## 安装与使用

将 `talent_editor-forge-1.20.1-1.3.0.jar` 放入客户端和服务端的 `mods` 目录，使用 Java 17 启动游戏。管理员按 `F8` 打开编辑器，玩家按 `J` 打开天赋册；按键可在控制设置中修改。联机时两端须使用相同构建。

可编辑天赋、稀有度、抽取池、计数器、进阶与合成关系、布局及自定义物品，并在游戏内导入、导出配置和资源包。

1.3.0 增加天赋册与抽取页面的可视化画布编辑，可拖动、缩放和预览背景、按钮、天赋格及文字，调整图片、透明度、位置和入口功能。编辑器页面统一样式并简化重复操作；获得演出支持文字、音效、粒子和模型效果，完善完整预览、文字换行及逐条停留时间。

天赋点默认加入宝箱战利品，5% 概率产出 1 个，可在物品编辑器中修改或关闭；匹配范围见 [默认战利品说明](docs/DEFAULT_LOOT_1.3.0.md)。

世界配置位于 `<世界>/datapacks/talent_editor_generated/`。自定义图片和音效需要启用配套客户端资源包；多人游戏的其他客户端也需要这些资源。

## 构建

使用 Java 17 执行 `./gradlew build`（Windows 为 `gradlew.bat build`）。JAR 与源码 JAR 位于 `build/libs/`。配置格式见 [文档](docs/SCHEMA_V2.md)，界面编辑见 [使用说明](docs/UI_EDITOR_1.3.0.md)。
