# Changelog

## 1.3.0

The 2026-10-15 presentation update fixes full-preview phase selection and multiline text, adds per-message chat holds, and plays acquisition voice cues without positional attenuation. The paired Ripples pack uses staggered text and continuous themed particles with an audio tail. See [presentation changes](docs/PRESENTATION_POLISH_1.3.0.md).

Visual UI editing for the talent book and draw screen, with drag/resize, layers, styling, action bindings, undo/redo and local preview. Legacy layouts remain supported. Editing now starts from the existing default interface, with native button styling. Duplicate geometry/preview editors were consolidated into a canvas and a page-content editor; added grouped properties, zoom/pan and persistent layers. Network protocol 46.

The 2026-10-13 logic update fixes interrupted canvas gestures, partial pack import rollback, conditional fixed attributes, same-ID talent/item trigger isolation, stale editor metadata, and renamed counter references. It also caches draft rendering and synthesis candidates, reduces redundant synchronization and condition scans, and consolidates the six definition submission paths. See [logic fixes and verification](docs/LOGIC_FIXES_1.3.0.md).

See [release notes](RELEASE_NOTES_1.3.0.md).
