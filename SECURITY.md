# Security Policy / 安全策略

Version 1.x for Minecraft 1.20.1 receives security fixes.

Please report vulnerabilities privately through GitHub Security Advisories. Include the affected version, reproduction steps, impact, and any suggested mitigation. Do not publish exploits in a public issue before a fix is available.

1.x（Minecraft 1.20.1）接受安全修复。请通过 GitHub Security Advisories 私下报告漏洞，并提供受影响版本、复现步骤、影响和建议的缓解方式；修复发布前请勿在公开 Issue 中披露利用方法。
